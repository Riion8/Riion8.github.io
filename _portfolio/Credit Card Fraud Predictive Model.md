# Requirements

To use this repository please ensure that you have Jupyter Notebook install with
the following modules.

- Pandas

- NumPy

- Matplotlib

- Sklearn


[Repository](https://github.com/Riion8/Data-Science-Portfolio/tree/main/Credit%20Card%20Fraud)



# Contents

- creditcard_2023.csv - Raw Data

- Credit Card Fraud Notebook.ipynb - Jupyter Notebook that contains the analysis and models

- Credit Card Fraud White Paper.docx - Paper discussing the analysis and models

- Presentation of White Paper.pptx - Presentation of the paper

- Presentation of White Paper.mp4 - Recording of the presentation 



# Summary

This model analysis and model is intended to present several methods that could be used to attempt to predict if a credit card transaction is fraudulent.  The model evaluated 550,000 credit card transactions that have had all data anonymized.
