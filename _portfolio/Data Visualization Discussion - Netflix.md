# Contents

- all-weeks-countries-netflix.xlsx - Raw Data File

- all-weeks-global-netflix.xlsx - Raw Data File

- most-popular-netflix.xlsx - Raw Data File

- Netflix Visualizations Workbook.twbx - Tableau Workbook that contains the constructed visualizations

- Netflix Visualization Discussion.docx - Discussion of why the visualizations were chosen for the target audience.

- Netflix Visualization Presentation.pptx - Presentation to the target audience.

- Netflix Visualization Presentation Recording.mp4 - Recording of the presentation to the target audience.


# Summary

The intent with this project was to create and discuss a series of visualizations.  The visualizations are designed to provide a consistent and focused story that is intended to be presented to a leadership group.
