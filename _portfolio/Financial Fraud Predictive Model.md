# Summary

This model analysis and model is intended to present several methods that could be used to attempt to predict if a financial transaction is fraudulent.  This model uses a synthetic data set to allow for development without any exposing real user data.  This data set covers multiple different types of financial transactions including, ATM withdraws, credit card, debit card, and others.
